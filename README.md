# SaveProfileSwitcher

App-only .NET 8 WPF foundation for managing save profiles per game and emulator.

## Build

```powershell
dotnet build SaveProfileSwitcher.sln
```

## Run

```powershell
dotnet run --project SaveProfileSwitcher.App/SaveProfileSwitcher.App.csproj
```

This initial app-only release intentionally has no Playnite dependency.
